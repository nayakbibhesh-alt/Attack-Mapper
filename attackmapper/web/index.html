Scan a target

Give AttackMapper a URL. It runs a read-only recon pass — HTTP headers, TLS, exposed paths, CORS, and an optional nmap sweep of common ports — and reports vulnerabilities, the attack path from the internet in, and a remedy for each finding.

Only point this at a target you own or are explicitly authorized to test. AttackMapper never attempts exploitation — every probe is a read-only GET, TLS handshake, or TCP connect/version scan.
